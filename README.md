# Gleam — Jewelry Management Landing Page Template

Ultra‑modern, production‑ready landing page for a jewelry management system. Built with semantic HTML, modern CSS (glassmorphism, aurora gradients), and vanilla JS micro‑interactions (reveal on scroll, 3D tilt, parallax, magnetic buttons).

## Quick start

1. Open `index.html` in your browser.
2. Customize copy, colors, and sections as needed.

No build step required. All assets are inline or local.

## Structure

- `index.html`: Semantic layout for hero, features, showcase, and pricing.
- `styles.css`: Theme, components, animations, and responsiveness.
- `script.js`: Interactions (reveal, tilt, parallax, magnetic, smooth scroll).

## Customize

- Colors: Edit CSS variables in `:root` inside `styles.css`.
- Sections: Duplicate feature or gallery cards in `index.html`.
- Motion: The page honors `prefers-reduced-motion` automatically.

## Notes

- Designed mobile‑first and responsive up to desktop.
- Uses system fonts as fallback and "Plus Jakarta Sans" from Google Fonts.
- No external JS dependencies.
